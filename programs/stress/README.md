# programs/stress/ — Matrix-GM Stress Test Programs

This directory contains `.soga` programs used by the stress-test campaign in
`tests/stress_matrix_gm/`.  All programs are automatically generated by the
test helpers; they are checked into the repository so test runs are
reproducible without regenerating them.

## Naming convention

```
{op}_{shape}_{covkind}_{idx}.soga
```

| Component | Values | Example |
|-----------|--------|---------|
| `op`      | `constructor`, `left_affine`, `right_affine`, `sum`, `transp`, `isserlis`, `extract`, `write`, `observe_ineq`, `observe_eq`, `observe_o7`, `mc_*` | `left_affine` |
| `shape`   | `1x1`, `2x2`, `3x3`, `8x8`, `16x16`, `2x3`, `3x2` | `2x2` |
| `covkind` | `kron`, `dense`, `iso` | `kron` |
| `idx`     | 1-based integer when multiple programs for the same (op, shape, covkind) | `1` |

## Categories

- **ops_** prefix: analytical ground-truth programs (30 total, P1–P26 + variants)
- **mc_** prefix: Monte Carlo validation programs (15 total, MC-1 through MC-15)

## Running

Programs are not meant to be run directly.  The test suite in
`tests/stress_matrix_gm/` invokes SOGA via subprocess and parses the output.
To run a single program manually:

```bash
python3 src/SOGA.py -f programs/stress/ops_constructor_2x2_kron_1.soga
```
